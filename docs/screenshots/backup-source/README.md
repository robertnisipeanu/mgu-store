# Backup source phone page

These browser captures use the phone page's actual HTML and JavaScript at a
430 × 932 viewport, served locally with synthetic API state. They demonstrate
configuration, saving the fallback choice, and turning the backup off.
`backup.example.org` is a placeholder, not a bundled service.

- `before.png`: the phone page from official main `6e80c4d`.
- `after.png`: a configured backup, the verification time, and the fallback
  switch enabled.
- `phone-flow.webm`: setting the URL and fallback choice, saving, and turning
  the backup off.

These are browser UI fixtures, not head-unit emulator or real-car captures.
